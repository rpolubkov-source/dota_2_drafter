# 🏆 Dota 2 Tournament Drafter (20 Heroes • 3 Bans Each)

Интерактивный киберспортивный веб-сайт для драфта турнирных матчей Dota 2 с уникальной механикой пула и начальных банов.

---

## 🎮 Правила и особенности формата

1. **Случайный пул из 20 героев**:
   - Ровно **5 героев Силы (Strength)** 🔴
   - Ровно **5 героев Ловкости (Agility)** 🟢
   - Ровно **5 героев Интеллекта (Intelligence)** 🔵
   - Ровно **5 героев Универсалов (Universal)** 🟣
   - Всего в базе 126 официальных актуальных героев Dota 2 (включая Kez и Ringmaster).
2. **Фаза начальных банов (по 3 бана)**:
   - В самом начале драфта каждая команда делает по 3 бана (всего 6 героев блокируются).
   - Очередность банов: `Команда 1 ➔ Команда 2 ➔ Команда 1 ➔ Команда 2 ➔ Команда 1 ➔ Команда 2`.
3. **Фаза пиков (по 5 пиков)**:
   - Из оставшихся 14 героев команды поочередно набирают себе по 5 героев (всего 10 героев выбираются, 4 остаются невыбранными).
   - Поддерживается турнирная "змейка" (1-2-2-2-2-1) или стандартное чередование (1-1-1-1...).
4. **Таймер на ход**:
   - Настраиваемое время (15с, 30с, 45с, 60с или без таймера) с предупреждающими звуками на последних 5 секундах и кнопкой паузы для судьи.
5. **Звуковые эффекты (Web Audio API)**:
   - Аутентичные процедурные звуки гонга старта, звука бана, героического аккорда пика, таймера и фанфар победы (без внешних аудио-файлов, работает 100% стабильно).
6. **Турнирные инструменты**:
   - **Жеребьевка (монетка 🪙)** для определения первого хода перед началом драфта.
   - **Сид генерации (Seed / URL hash)**: ссылка вида `index.html#seed=DOTA-XXXX` позволяет зрителям, кастерам и судьям видеть абсолютно идентичный пул из 20 героев.
   - **Отмена хода (`Undo` / `Ctrl+Z`)** на случай судейского решения или миссклика.
   - **Экспорт результатов**: кнопка копирования красивой сводки драфта в Discord, Telegram или VK.

---

## 🚀 Как запустить

Веб-приложение полностью автономно и не требует сборки или установки Node.js/Python:
1. Просто откройте файл `index.html` в любом современном браузере (Google Chrome, Microsoft Edge, Firefox, Opera, Safari) двойным кликом.
2. Либо запустите любой статический HTTP-сервер (например, GitHub Pages, Vercel, Live Server).
