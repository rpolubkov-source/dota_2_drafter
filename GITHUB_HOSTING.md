# 🌐 Инструкция: Как бесплатно захостить сайт на GitHub Pages

GitHub Pages позволяет бесплатно опубликовать этот сайт в интернете, чтобы любой человек (и второй капитан) мог открыть его по ссылке с телефона или компьютера.

---

## ⚡ Быстрый способ через браузер (без командной строки за 2 минуты)

### Шаг 1. Создайте репозиторий на GitHub
1. Перейдите на сайт [github.com](https://github.com) и войдите в свой аккаунт (или зарегистрируйтесь).
2. В правом верхнем углу нажмите на иконку **`+`** ➔ **`New repository`**.
3. В поле **Repository name** введите название, например: `dota2-drafter`.
4. Убедитесь, что выбран пункт **Public** (публичный).
5. Нажмите зеленую кнопку **`Create repository`** внизу.

---

### Шаг 2. Загрузите файлы сайта
1. На открывшейся странице репозитория найдите строчку:  
   *«...or push an existing repository from the command line»* или чуть выше ссылку: **`uploading an existing file`** (нажмите на неё).
2. Откройте папку сайта на компьютере:
   ```text
   C:\Users\rpolu\Documents\antigravity\jolly-babbage
   ```
3. Выделите и перетащите мышкой в окно браузера следующие файлы и папки:
   - 📄 `index.html`
   - 📁 `src/` (со всеми файлами внутри: `bundle.js`, `style.css`, `peerjs.min.js`, `heroes.js` и т.д.)
   - 📄 `README.md`
4. Внизу страницы нажмите зеленую кнопку **`Commit changes`**.

---

### Шаг 3. Включите GitHub Pages
1. В вашем репозитории перейдите во вкладку **Settings** (вкладка с шестеренкой справа вверху).
2. В левом боковом меню найдите раздел **Pages** (под разделом *Code and automation*).
3. В блоке **Build and deployment**:
   - **Source**: выберите `Deploy from a branch`.
   - **Branch**: выберите `main` (или `master`), а в соседнем выпадающем списке оставьте `/(root)`.
   - Нажмите кнопку **Save**.
4. Обновите страницу через 1-2 минуты. Вверху появится зеленая плашка с адресом вашего работающего сайта:
   ```text
   Your site is live at https://<ваш_логин>.github.io/dota2-drafter/
   ```

---

## 🎮 Как теперь играть вдвоем (2 капитана):

1. **Капитан 1 (Radiant)**:
   - Открывает опубликованный сайт `https://<ваш_логин>.github.io/dota2-drafter/`.
   - В правом верхнем углу нажимает кнопку **`🌐 Онлайн (2 капитана)`**.
   - Нажимает кнопку **`➕ Создать комнату`**.
   - Появится код комнаты (например, `A7F2B`) и кнопка **`📋 Копировать ссылку для Капитана Dire`**.
   - Отправляет эту ссылку второму капитану в Discord / Telegram / Steam.

2. **Капитан 2 (Dire)**:
   - Просто переходит по присланной ссылке.
   - Сайт автоматически подключится к комнате как Капитан Dire.

3. **Процесс драфта**:
   - На экранах обоих игроков статус загорится зеленым: **«🟢 Соперник подключен»**.
   - Каждый капитан может выбирать и блокировать героев **только в свой ход**. Когда ходит соперник, кнопка блокируется и показывает: *«⏳ Ход соперника...»*.
   - Все баны, пики, таймер и звуки синхронизируются в реальном времени!
   - Третью ссылку можно дать зрителям или вывести на стрим (режим просмотра).
